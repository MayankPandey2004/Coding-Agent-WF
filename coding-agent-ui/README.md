# CodeSmith UI

Modern web interface for the CodeSmith agent, built with Next.js.

## Setup

1.⁠ ⁠Clone the repo
2.⁠ ⁠Install dependencies: ⁠ npm install ⁠
3.⁠ ⁠Add your API keys to ⁠ .env.local ⁠
4.⁠ ⁠Run: ⁠ npm run dev ⁠
5.⁠ ⁠Open http://localhost:3000

## Deployment

Push to GitHub, connect to Vercel, add secrets, and deploy.
